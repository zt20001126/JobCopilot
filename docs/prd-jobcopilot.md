# JobCopilot（AI 求职副驾驶）产品需求文档

| 项目 | 内容 |
| --- | --- |
| 产品形态 | Chrome / Edge 浏览器插件 |
| 目标平台 | Boss直聘 |
| 当前阶段 | MVP |
| 目标用户 | 应届生、校招生、社招及高频投递用户 |

## 1. 产品概述

JobCopilot 是一款面向求职者的 AI 浏览器插件。用户浏览 Boss直聘岗位详情页时，插件自动识别职位名称与岗位描述（JD），并基于岗位要求生成 3 条有针对性的招呼语，帮助用户快速发起沟通并提高 HR 回复概率。

## 2. 背景与用户痛点

在 Boss直聘等招聘平台中，求职者通常需要先向 HR 发送消息，获得回复后才能进一步沟通。当前存在以下问题：

- **内容同质化严重**：大量用户发送“对岗位感兴趣”“可以看看我的简历吗”等模板化内容，难以形成区分。
- **针对性不足**：求职者没有结合岗位要求表达匹配点，HR 难以快速判断沟通价值。
- **编写成本较高**：逐个阅读 JD 并编辑个性化招呼语耗时，影响投递效率。
- **表达质量不稳定**：部分用户不清楚如何在短消息中兼顾礼貌、专业与真实。

## 3. 产品目标

### 3.1 核心目标

- 根据当前岗位 JD 快速生成自然、真实、有针对性的招呼语。
- 降低用户逐个岗位编写消息的时间成本。
- 提升求职者发起沟通的效率与 HR 回复概率。

### 3.2 产品价值

**对求职者：**

- 从通用模板升级为岗位定制表达。
- 将招呼语准备时间由数分钟缩短至数秒。
- 提供不同表达风格，降低求职沟通门槛。

**对产品：**

- 以高频、低门槛场景切入求职流程。
- 为后续简历匹配、面试准备和求职分析积累场景基础。

### 3.3 MVP 成功指标

| 指标 | 建议目标 |
| --- | --- |
| 岗位信息识别成功率 | ≥ 95% |
| 招呼语生成成功率 | ≥ 98% |
| 首次结果返回时间 | ≤ 10 秒 |
| 生成结果复制率 | ≥ 60% |
| 用户满意度 | ≥ 80% 用户认为结果“可直接使用或简单修改后使用” |

> HR 回复率受岗位、候选人背景和市场环境影响，MVP 阶段以用户授权或主动反馈方式进行验证，不承诺固定提升幅度。

## 4. 用户与使用场景

### 4.1 核心用户

- **应届毕业生 / 校招生**：求职沟通经验少，需要表达指导。
- **社招用户**：希望快速突出与岗位相关的能力。
- **高频投递用户**：每天浏览和沟通多个岗位，重视效率。

### 4.2 核心场景

用户在 Boss直聘浏览岗位详情，希望快速生成与该岗位相关、可直接发送给 HR 的首轮招呼语。

## 5. 用户流程

1. 用户打开 Boss直聘岗位详情页。
2. 插件自动读取职位名称与岗位描述。
3. 用户打开插件并点击“AI 生成招呼语”。
4. 系统分析 JD 并生成 3 条不同风格的结果。
5. 用户选择合适内容并一键复制。
6. 用户返回招聘页面，将内容发送给 HR。

异常情况下，插件应明确提示岗位信息未识别、生成失败或网络异常，并允许用户重试。

## 6. MVP 核心功能

### 6.1 岗位信息提取

**功能描述**

插件在 Boss直聘岗位详情页自动识别并提取：

- 职位名称
- 岗位描述（JD）

**交互要求**

- 打开插件后展示已识别的职位名称。
- 未识别到有效 JD 时，不进入生成流程，并提示用户确认当前页面是否为岗位详情页。
- 用户切换岗位页面后，插件应读取当前岗位信息，避免沿用上一岗位内容。

**验收标准**

- 在正常可访问的岗位详情页中，可正确获取职位名称和主要岗位描述。
- 非岗位详情页中不生成无关内容。
- 岗位切换后，生成结果对应当前页面岗位。

### 6.2 AI 招呼语生成

**功能描述**

用户点击“AI 生成招呼语”后，系统基于当前岗位 JD 返回以下 3 种风格：

1. **简洁版**：表达直接，突出兴趣和核心匹配点。
2. **专业版**：语气正式，体现对岗位职责或要求的理解。
3. **高回复率版**：更具沟通感，通过具体岗位信息增强回复意愿。

**内容要求**

- 每条不超过 100 个汉字。
- 明确体现与当前岗位的关联，不生成可套用于所有岗位的空泛内容。
- 语言自然、礼貌、简洁，适合首次联系 HR。
- 不虚构或夸大用户经历、技能、学历、年限及成果。
- 未上传简历时，不使用“我拥有相关经验”等无法验证的个人陈述。
- 3 条结果在语气和表达结构上有明显差异。

**状态要求**

- 生成期间展示加载状态，防止重复提交。
- 生成失败时展示原因说明和“重新生成”入口。
- 每次重新生成仍返回 3 条符合要求的结果。

**验收标准**

- 成功时一次返回 3 条完整招呼语，并标明风格。
- 每条内容不超过 100 个汉字。
- 内容包含职位名称、职责、技能或岗位特点中的至少一项有效信息。
- 结果不包含未经用户提供的个人经历。

### 6.3 一键复制

**功能描述**

每条生成结果均提供独立复制按钮。

**交互要求**

- 点击后将对应完整文本写入剪贴板。
- 复制成功后显示明确反馈，如“已复制”。
- 不自动发送消息，由用户确认后自行发送。

**验收标准**

- 任意结果均可独立复制。
- 剪贴板内容与所选结果一致。
- 复制操作不改变或清空其他生成结果。

## 7. MVP 页面与信息结构

插件主界面包含：

- 产品名称与当前状态
- 当前职位名称
- “AI 生成招呼语”按钮
- 加载、成功、失败状态提示
- 3 个结果卡片及对应风格标签
- 每个结果的“一键复制”按钮
- 必要的隐私说明入口

界面应保持单一任务导向，不增加简历管理、账号中心等非 MVP 入口。

## 8. MVP 边界

### 8.1 本期包含

- 支持 Chrome 和 Edge。
- 支持 Boss直聘岗位详情页。
- 自动提取职位名称和岗位描述。
- 根据 JD 生成 3 种风格、每条 100 字以内的招呼语。
- 支持重新生成和一键复制。
- 提供必要的加载、错误和成功反馈。

### 8.2 本期不包含

- 简历上传、解析及简历信息参与生成。
- 自动填写或自动发送招聘平台消息。
- 批量抓取岗位、批量生成或批量投递。
- 匹配度评分、关键词匹配和简历优化。
- 面试问题预测或求职分析报告。
- 用户账号、会员、支付及使用次数管理。
- Boss直聘以外的招聘平台。
- HR 回复率的确定性承诺。

## 9. 非功能需求

- **性能**：正常网络环境下，点击生成后 10 秒内返回结果。
- **兼容性**：支持当前主流版本的 Chrome 和 Edge。
- **易用性**：核心任务在“打开插件—生成—复制”三个主要操作内完成。
- **稳定性**：页面信息提取或生成失败时，不展示错误或过期岗位内容。
- **隐私性**：仅处理完成功能所必需的岗位信息；未经用户明确授权，不采集简历或招聘平台账号敏感信息。
- **合规性**：明确 AI 生成内容仅供辅助，由用户确认后发送；遵守招聘平台规则及相关隐私要求。
- **可扩展性**：产品结构应支持后续适配其他招聘平台，但 MVP 不要求实现。

## 10. 风险分析

| 风险 | 影响 | 应对原则 |
| --- | --- | --- |
| 招聘平台页面结构调整 | 无法正确提取 JD | 监控识别失败率，及时更新页面适配规则 |
| 平台限制插件读取页面 | 核心功能不可用 | 上线前确认平台规则与浏览器插件权限合规性 |
| AI 内容模板化或相关性低 | 用户信任和复制率下降 | 强化岗位信息引用与三种风格差异，收集用户反馈 |
| AI 虚构个人经历 | 引发误导和诚信风险 | MVP 仅依据 JD 表达兴趣与理解，不生成未经提供的个人事实 |
| 响应过慢或调用失败 | 中断用户投递流程 | 提供超时提示、失败重试和清晰状态反馈 |
| 岗位数据与隐私风险 | 合规和用户信任受损 | 最小化采集、明确用途，不默认长期保存岗位内容 |
| 回复率难以准确归因 | 产品价值验证困难 | 结合复制率、满意度及用户主动反馈综合评估 |

## 11. 版本规划

### V1：岗位与简历匹配

- 上传并解析简历
- JD 分析与简历分析
- 岗位匹配度评分
- 关键词匹配
- 基于真实简历信息生成更个性化的招呼语

### V2：求职准备

- 面试问题预测
- 简历优化建议
- AI 求职分析报告

### V3：规模化与商业化

- 批量岗位分析
- 批量生成招呼语
- 用户系统
- 会员系统
- 使用次数管理

## 12. 商业化方向

- **免费增值模式**：免费用户获得基础生成次数，会员获得更多次数和高级风格。
- **订阅会员**：按月或按季度提供简历匹配、面试预测和求职报告等能力。
- **增值服务**：单次售卖简历深度优化、岗位匹配报告或面试准备包。
- **场景套餐**：面向校招季、转岗期或高频求职用户提供阶段性套餐。
- **合作拓展**：与高校就业服务、职业培训及求职服务机构开展合规合作。

商业化应建立在基础生成质量和用户留存得到验证之后，MVP 阶段不引入付费流程。

## 13. 上线验收条件

满足以下条件后可视为 MVP 达到上线标准：

- Chrome 与 Edge 均可正常安装和使用。
- Boss直聘岗位详情页信息识别成功率达到目标。
- 可稳定生成 3 条不同风格、100 字以内且不虚构经历的招呼语。
- 生成响应时间、成功率达到目标要求。
- 一键复制、重新生成及异常提示可用。
- 已完成必要的隐私说明、权限说明和平台合规检查。
