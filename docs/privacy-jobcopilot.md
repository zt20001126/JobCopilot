# JobCopilot 隐私说明

## 1. 数据处理范围

JobCopilot 仅在用户打开支持的招聘岗位页面并主动生成时处理：

- 职位名称
- 岗位描述（JD）
- 当前岗位 URL

MVP 不读取招聘账号密码、聊天记录、联系人、Cookie、浏览历史或简历。

## 2. 数据流向

岗位信息由浏览器插件发送到用户配置的 JobCopilot 后端，再由后端发送至 DeepSeek API 生成招呼语。DeepSeek API Key 仅保存在后端环境变量中，不写入插件、源码或数据库。

## 3. 数据存储

- 插件不持久化岗位信息和生成结果。
- 后端默认 `STORE_JOB_DESCRIPTION=false`，数据库不保存完整 JD。
- 数据库仅保存请求标识、职位名称、平台、模型、状态、耗时和生成结果等运行记录。
- 日志不记录 API Key、完整 JD 或第三方响应正文。

## 4. 浏览器权限

| 权限 | 用途 |
| --- | --- |
| `https://www.zhipin.com/*` | 在 Boss直聘岗位页读取职位名称和 JD |
| 后端 API 域名 | 将岗位信息发送至用户配置的后端 |
| `sidePanel` | 展示生成结果和复制入口 |

插件不申请通用浏览历史、下载、Cookie、身份认证或后台标签页访问权限。

## 5. 用户控制

- 仅在用户点击生成按钮时调用 AI。
- 生成结果由用户确认并手动复制，插件不会自动向 HR 发送消息。
- 用户可在浏览器扩展管理页停用或删除插件。
- 用户可通过关闭后端服务立即停止外部 AI 请求。

## 6. 部署建议

- 生产环境使用 HTTPS。
- DeepSeek API Key 使用部署平台的密钥管理能力保存。
- 对外部署时将内存限流替换为共享限流服务。
- 上线前根据实际部署主体补充隐私政策主体、联系方式和数据保留期限。
